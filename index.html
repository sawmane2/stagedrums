    Import a song
    
    
    Paste a chord chart (Ultimate Guitar "Chords" page copied as text) or a StageDrums song JSON. Section headers like [Verse 1] / [Chorus] are detected. Each chord line becomes bars; edit afterwards if the bar count is off.
    
    
    
      
      
      
      
      
      
    
    
    
    
    
    
      
      
      
    
    
  
    
    



  
    
    
    Edit song JSON
    
    
    Sections have name, groove (see list below), optional repeat, and bars — each bar is a string of chords, e.g. "G", "G D" (two chords, half bar each) or "Am . . G" (dots hold). Instruments in grooves: K S H D C T M F R B(cowbell). Optional fill: true plays a fill on the last bar, crash: true crashes on bar 1. lyrics (one line per chart line) is spread across the section's bars and shown on stage; use lyricBars (an array with one entry per bar) to place lines exactly. For a pasted sheet, sheetBars (bars per chord line, e.g. [4,4,2,2]) pins the chord highlights to the right bars. swing (0–1) and feel (loose / push / tight) override the groove's feel.

    Connect to host
    
    
    Run node server.js on the computer, then enter that computer's address (shown in its terminal), e.g. ws://192.168.1.20:8080. Both devices must be on the same Wi‑Fi (or the computer's hotspot).
